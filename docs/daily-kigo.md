# 今日の季語

トップページの既存の季節イラストの横に、季語だけを小さく表示します。PC・スマートフォン共通です。クリック／タップ、Enter／Spaceで、日付・読み・季節・意味・情景を含む詳細を開閉できます。詳細はナビゲーションより下に重ねて表示し、本文の位置を動かしません。閉じるボタン、Escape、欄の外のタップでも閉じられます。画面を覆うモーダルではありません。

## データを編集する

`content/kigo.json` が唯一の編集元です。月日を `MM-DD` で指定し、366日分（2月29日を含む）を保持します。平年には2月29日の項目を使いません。毎年同じ月日には同じ項目が出ます。

```json
"10-18": {
  "term": "秋深し",
  "reading": "あきふかし",
  "season": "秋",
  "summary": "秋が深まったころ。静けさや物寂しさも含む言葉。",
  "scene": "色づく木々と早い日暮れに季節の深さを感じる。",
  "source": "https://kigosai.sub.jp/001/archives/2525"
}
```

- `term`：季語の表記。366件で同じ表記を重複させない。
- `reading`：平仮名の読み。歴史的表記の季語はその語形も尊重する。
- `season`：`春`・`夏`・`秋`・`冬`・`新年` のいずれか。
- `summary`：詳細表示に使う、意味・由来の簡潔な説明（1〜2文）。
- `scene`：その言葉が表す景色の説明。引用・古典の例句ではなく、理解のための短い説明。
- `source`：参考歳時記の該当記事、または掲載一覧のURL。詳細表示から参照できる。

編集後は `python build.py` で再生成します。ビルド時に `kigo.py` が日付の欠落・余分な日付・JSONのキー重複・季語の表記重複・必須項目・読みの文字種・季節分類の値・出典URL形式を検査します。失敗したデータはビルドできません。ただし、機械的な検査だけでは読みや説明の正しさまでは保証できません。

ビルドしたトップページのJSON要素にデータを埋め込みます。HTML内では `<`・`>`・`&` をエスケープし、表示には `textContent` を使います。外部API、ランダム選択、Cookie、ローカルストレージは使いません。実行時のデータ取得通信も不要です。

## 選定と確認の留意点

主な照合先は季語と歳時記の会の[季節別一覧](https://kigosai.sub.jp/kigoken3.html)です。表記の異なる子季語も採用しています。基礎的な語義を短く言い換え、出典の解説や俳句を転載していません。

- 季語分類は伝統的な歳時記を基準にします。現代の日常感覚と一致しないもの（朝顔＝秋、麦の秋＝夏、水仙＝冬など）があります。初夏の若葉・新緑のように関連する語も、異なる言葉として選定しています。
- この表は季節の言葉を紹介する固定の年間選定表であり、その年の開花・気象や行事予定を示す暦ではありません。地域・標高・年によって実景は変わります。春秋の境界も年ごとの節気時刻には連動しません。
- 二十四節気、八十八夜、半夏生、秋彼岸、後の月には年による日付変動があります。紹介日は代表的な時期に固定し、説明には日付が変わることを明記しています。「今日は必ずその節気・行事の日」とは表示しません。後の月は旧暦九月十三夜として説明し、新暦十月二十七日に固定された行事とは扱いません。
- 元日、七草、小正月、雛祭、灌仏会、端午、夏越の祓、重陽、文化の日、七五三、新嘗祭、聖夜、クリスマス、除夜の鐘は対応する月日に配置しています。鏡開・針供養・盆・迎火・送り火などには地域差があることを説明に残しています。
- 釈迦誕生を祝う春の行事には「灌仏会」を採用し、冬の民俗芸能も指す「花祭」との混同を避けています。[歳時記の仏生会の項](https://kigosai.sub.jp/001/archives/1960)、[天台宗の説明](https://www.tendai.or.jp/houwashuu/kiji.php?nid=6)を参照。
- 「蒲公英の絮」は[蒲公英の子季語](https://kigosai.sub.jp/001/archives/2012)、「寒梅」は[主要季語の冬の部](https://kotobank.jp/word/季語-473181)も参照しています。[秋深し](https://kigosai.sub.jp/001/archives/2525)、[夕焼](https://kigosai.sub.jp/001/archives/2048)、[熱帯夜](https://kigosai.sub.jp/kigo500c/814.html)なども個別項目を照合しました。
- 全366件の専門家による校閲や、全出典ページの全文を使った逐語照合を終えたデータという扱いではありません。読み・季節分類・語義の編集時には、掲載一覧だけでなく該当する個別項目や信頼できる辞書も確認してください。確認できない語を推測で追加せず、確認できる語に差し替えます。

## 日付と操作

`assets/kigo.js` は `Intl.DateTimeFormat` の `Asia/Tokyo` で月日を求め、次の日本時間午前0時までのタイマーを毎回予約します。背景タブのタイマー停止やスリープに備え、`visibilitychange`・`pageshow`・`focus` でも再確認します。日付が変わると詳細を閉じて新しい季語に更新します。端末時計が正しいことが前提です。

JavaScript無効時は誤った日付の季語を表示せず、季語欄を非表示にします。既存のナビゲーションや本文は利用できます。他のページには季語用HTML・CSS・JS・JSONを読み込みません。

## 検証とプレビュー

```sh
python -m unittest discover -s tests -p 'test_*.py'
python build.py
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/kigo.browser.cjs
node --test tests/seasonal.test.cjs
python scripts/seasonal-preview.py
node tests/seasonal.browser.cjs
```

システムのChromiumを使う場合は `CHROMIUM_PATH=/usr/bin/chromium` をブラウザーテストに付けてください。

季語テストは366日すべての実ブラウザー表示、平年／閏年の二月末、日／月／年の境界、ページを開いたままの日本時間0時の更新、別タイムゾーン、再読込、復帰、キーボード、タップ、閉じる操作、トップ以外への非表示、JavaScript無効を検証します。幅1280・768・600・390・320pxと12か月の配色で、開いた状態の横はみ出し・ナビと本文の重なりも確認します。`.private/kigo-screenshots/` にPC・タブレット・スマートフォンの開閉状態を保存します。

`python scripts/seasonal-preview.py` は季語も含めた単体確認用HTMLを `.private/seasonal-preview.html` に生成します。ファイルをブラウザーで開けます。プレビューの月選択は配色だけを切り替え、季語は実際の日本時間の日付を表示します。リンク先は公開サイトです。

PRの **Check seasonal themes** が両方のブラウザーテストを実行し、**seasonal-theme-preview** アーティファクトに確認用HTMLとスクリーンショットを保存します。本番反映はmainへのマージ時です。
