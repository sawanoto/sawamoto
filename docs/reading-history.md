# 読書遍歴の編集

ページは `/sawamoto/reading/`（`SITE_BASE_PATH` に追従）。既存サイトと同じく `python build.py` で `dist/` に生成し、mainへのpush後、既存のGitHub Pagesワークフローで公開されます。今回の作業ではデプロイしていません。

## 作品の追加・追記

`content/reading.json` の配列に次のようなオブジェクトを追加します。`content/books.json` は販売作品用なので変更しません。

```json
{
  "id": "book-088",
  "title": "作品名",
  "author": "",
  "period": "時期不明",
  "period_note": "",
  "genres": ["その他"],
  "medium": "",
  "status": "記録あり（読了未確認）",
  "reviews": [],
  "impression": "",
  "featured": false,
  "related_ids": []
}
```

- `id` は重複しない半角英小文字・数字・ハイフン。公開後はリンクを保つため変更しません。番号は評価や順位ではありません。
- `title`、`id` は必須。ほかは省略可能です。著者・媒体の空欄は「未整理」、感想なしは「感想は今後追記」と表示します。
- `period` は「幼少期／小学生／中学生／高校生／大学生／社会人／時期不明」。不明なら省略または「時期不明」。高校・大学前後などは `period_note` に書き、確定するまで「時期不明」に置きます。
- `genres` は「SF／海外文学／日本文学／歴史小説／ライトノベル／ノンフィクション／思想・社会／その他」の配列。先頭を主ジャンルとして分類し、絞り込みはすべてのジャンルが対象です。
- `medium` は「紙の本」「Audible」「漫画版」など。原作と漫画版を別々に記録する場合は別IDにして関連付けできます。
- `status` は「読了」「全巻読了」「複数巻読了」「再読」「途中で中断」「未読」「読書中」「読了範囲未確認」「記録あり（読了未確認）」など。登録した値が絞り込みに自動追加されます。記録があるだけの作品を読了と推測しません。
- `reviews` に感想の段落を追加すると、既存の感想を残して追記できます。HTMLは不要で、そのままの文章として安全に表示します。
- `impression` は任意の短い印象メモ。点数や順位を必須にしません。
- `featured: true` で別枠の「特に印象に残った本」に感想と本文リンクが表示されます。
- `related_ids` に他作品のIDを追加すると、関連する本へのリンクが表示されます。

初期版はシリーズを含む87記録、別枠は指定の10作品です。生涯の読了冊数を示すものではありません。検索結果の件数も「記録」として表示します。子ども時代のシリーズは依頼の区分で整理しています。より細かい時期は今後確認できます。

## 書誌情報の確認待ち

『殺し屋の営業術』は出版社サイトへのアクセスが環境のネットワーク制限で拒否されたため、著者を空欄にして確認待ちにしています。末尾の未整理作品や、同名書籍の可能性があるものも推測で補完していません。感想や媒体の創作もしていません。依頼にあった『海賊とよばれた男』の著者の誤記は百田尚樹へ修正しています。

## 確認

```sh
python build.py
python -m unittest discover -s tests -p 'test_*.py'
node tests/reading.browser.cjs
```

Pythonは既存の `requirements.txt`、ブラウザテストはPlaywrightとChromiumが必要です。ローカルのChromiumが `/usr/bin/chromium` にあれば使用し、なければPlaywright付属のものを使用します。`CHROMIUM_PATH` でも指定できます。CIでは既存のブラウザ確認ワークフローに組み込んでいます。

生成HTMLには全記録が年代別に含まれ、JavaScriptが無効でも読めます。JavaScript有効時のみ絞り込みとジャンル別表示が有効になります。既存ページには読書用CSS・JSを読み込みません。
