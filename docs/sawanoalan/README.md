## 表示を確認する

PRの **Checks → Check content build** が成功したら、その実行画面の **Artifacts → sawanoalan-article-review** をダウンロードしてください。中の `review.html` を開くと、サーバーの準備なしで25件をまとめて読めます。確認事項も各記事に表示します。

ローカルでも次のコマンドで `.private/sawanoalan-preview/review.html` を作れます。実際のサイトのレイアウトで確認する場合は、続けてサーバーを起動してください。

```powershell
python scripts/preview-sawanoalan.py
python -m http.server 8000 --directory .private/sawanoalan-preview/dist
```

`http://localhost:8000/writing/` を開きます。確認用のコピーでだけ25件を公開状態にしてビルドします。編集元と通常の `dist/` は変えません。確認用ファイルは `.private/` 内でGit管理・本番デプロイ対象外です。

## 公開する

1. 対象の `content/writing/sawanoalan-*.md` を編集します。冒頭のタイトル・カテゴリ・タグ・要約と本文を確認してください。JSONの構文は維持します。
2. その記事の `"draft": true` を `"draft": false` に変更します。元の公開日は保持し、編集した日を `updated` に設定できます。
3. `python build.py` で確認し、変更をPRにコミットします。
4. PRをマージすると通常のGitHub Pages公開処理が走ります。Draft PRの解除だけでは公開されません。

旧サイトへの本文中リンクは、未公開の移植先へ誘導しないよう維持しています。両方の記事を公開した後、`url-map.json` の候補を使って `/sawamoto/writing/.../` に置き換えてください。この対応表は自動リダイレクトを設定しません。旧ドメイン側の転送は別途設定が必要です。

## 特別な確認が必要な記事

- 家族会議・月末決算電卓：スクリプト、入力欄、自動保存、計算は移植していません。元のアプリを実行せず、画面の文章と項目を保存しました。機能を再構築するか、紹介記事へ編集してから公開してください。
- 自分年表・じぶん年表・自伝：現在の年表・Aboutと統合するか判断してください。
- 動画制作サービス：現在のサービス提供条件を確認してください。
- 読書感想・店舗案内：引用、外部リンク、過去の記述を確認してください。

## 固定ページと画像

固定ページ7件は `pages/` に参照資料として保存しました。About・HOME・問い合わせ・プライバシーポリシー等は、新サイトの既存ページを上書きしていません。旧フォームのショートコードはそのままでは動きません。

回収した画像12ファイルは `media/` に保管し、元URLとの対応を `image-manifest.json` に保存しました。いずれも今回は公開用assetsへ自動追加していません。記事内の画像はリンクカードのキャッシュ・ファビコン・アフィリエイト装飾だったため、画像を除いて説明文とリンクを残しています。未回収のリンクカード画像2件も、本文の欠落にはなりません。画像を使う場合は必要なものを確認して `assets/images/` へコピーしてください。

この移植には認証情報、WordPress設定、秘密鍵、サーバー設定、バックアップアーカイブを含めていません。
