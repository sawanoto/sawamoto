`written` はノート作成日から得た参照日です。出来事の日や元の公開日は未確定で、`published` は設定していません。初公開にする場合は公開時に設定してください。EN-IDは今回のENEX内の順番による照合用IDで、EvernoteのGUIDではありません。

## 使い方の選択肢

- 当時の記録として残す：時期の注記を維持し、誤字・引用・実名・事実関係を確認する。
- 今の文章に育てる：原稿を編集し、当時と今の考えを分けて追記する。
- 既存記事に統合する：WordPress由来の読書感想やスキー・制作記事と比較して、自分の経験部分を取り込む。
- 年表の根拠にする：短期留学など、出来事と日付が確認できたものだけを既存年表へ反映する。
- 今回は使わない：下書きのまま保留できる。

読書・映画の下書きは書名、作品内容、引用と感想の境界を確認してください。俳句は自作・完成稿かの確認が必要です。留学の記録は第三者の私生活や発言の範囲を確認してください。元の作成日を公開日へ自動転用しません。

## 続けて検討できる素材

留学の日常、スキー観の変化、体験会や松明滑走の動画制作、学生劇の音響、検索支援システムの共同開発などが次の候補です。企画・予定を実績として扱わず、共同制作の帰属と公開範囲を確認してから追加します。年表への変更はこのPRに含めていません。

全件台帳、ENEX、添付一式、契約資料、私信、勤務先の内部資料はこのPRに含めていません。原本と私的台帳はローカルで保全しています。画像も追加していません。

## 確認と公開

GitHub上の各Markdownの本文と差分を確認できます。`python build.py` で通常ビルドし、6本が出力対象外であることを確認します。下書きの除外については既存の `tests/test_drafts.py` でも確認できます。

活用方法を決めて本文を確認した後、公開する記事だけ `draft` を `false` にし、`published` と要約を設定して別途レビューしてください。このPRをマージしても、6本の下書きは公式サイトには掲載されません。
