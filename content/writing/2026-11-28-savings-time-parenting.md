2026年11月27日、こども支援センターみんなの家＠ふくしまを訪れた。

今回は東北財務局の方を招いてのお金の講座である。参加者は6組ほどで、45分程度の説明の後、個別の質疑応答の時間が設けられていた。

妻と私は講座に参加し、娘二人は託児をお願いした。長女は膝の上で遊び、次女は抱っこされながら大人しく過ごしていたそうだ。夫婦でこうした講座を受けられる環境を用意していただけるのは、ありがたいことである。

講座では、子供を育てるのに必要な費用や老後資金、NISAを活用した資産形成などについて説明があった。

お金に関する講座では、こうした平均的な金額や制度についての話をよく耳にする。しかし、それらを知った上で、自分はどうすればよいのだろうか。

私は講座を聞きながら、次々と疑問を手帳に書き出していた。

## 何のためにお金を使うのか

寒さをしのぐために衣服が必要だとする。

ただ寒さをしのぐだけであれば、分厚い服を着ればよい。しかし、快適に過ごしたいのであれば、軽さや肌触り、動きやすさも重要になってくる。美しい服を着ることで日々の生活が楽しくなる人もいるだろう。

同じ衣服であっても、それに何を求めるかによって、支払うべき金額は異なる。

外食も自動車も住居も同様である。

支出の大小を考える前に、その支出によって何を得たいのかを考える必要がある。

そして、自分が望む生活に必要な金額が分かれば、それを得るために必要な労働量も見えてくるのではないだろうか。

収入に応じて生活を設計するだけでなく、生活に応じて労働を設計するという考え方もあってよいと思う。

## 子供の今に何を与えるか

子供のためにお金を貯めるという話も、よく耳にする。

しかし、幼い子供が今必要としているものは、必ずしもお金ではない。

幼い子供にとって、親や家庭は世界に踏み出すための足掛かりなのではないかと私は考えている。

自分とは何なのか。他者とはどのような存在なのか。世界は安心して過ごせる場所なのか。

子供は日々の生活の中で、こうした問いに対する答えを少しずつ見いだしているように思う。

その問いに対して、親が今できることを示す。

それは労働によってお金を稼ぐこととは別に、時間を与え、寄り添うという形での一つの答えでもある。

お金は後から稼げる可能性がある。しかし、子供の今は今しかない。

子供が切実に親を必要としているのであれば、その時間を子供に与えてもよいのではないだろうか。

## 見えない期待と、目の前の行動

一方で、将来の子供が親の経済的な支援を必要とすることもあるだろう。

大学に進学したい。留学したい。芸術や研究に取り組みたい。

そうした希望に対して、親として可能な限りの支援はしたいと思っている。

ただし、あらゆる希望を経済力によって実現できるようにしておくことが、親の役割であるとは考えていない。

例えば、18歳になった子供が絵画を学びたいと言い出したとする。

絵画を専門的に学ぶにはお金が必要かもしれない。しかし、絵を描くこと自体は今からでもできる。

描き続けられるのか。何を表現したいのか。学校の先生や絵画教室の先生に作品を見てもらうこともできる。作品を公開したり、販売を試みたりしてもよい。

そうした行動の中から、何を学ぶ必要があるのかが見えてくるのではないだろうか。

もちろん、親の価値観だけでその進路を判断する必要はない。本人や周囲の人々と話し合いながら、道筋を見極めればよい。

このことについて考えているうちに、自分自身の性質にも気がついた。

私は行動に対して支援することはできるが、見えない期待に対して支援することは苦手なようである。

限られた資源の中で何ができるのかを考え、自分なりの方法を見いだす力も、子供には身につけてほしいと思っている。

## 将来のための余白

とはいえ、将来何が起こるかは分からない。

失業することもあれば、病気になることもある。夫婦のどちらかが亡くなることも考えられる。

そのような事態に備えて、貯蓄や生命保険によって一定の余白を確保しておくことには意味がある。

ただ、その余白は、将来の生活を完全に保障するためのものである必要はないのではないか。

環境が変われば、その環境に応じて生活を組み立て直すことになる。住居や働き方を変えることもあるだろうし、周囲の人々や社会制度に助けを求めることもあるだろう。

貯蓄とは、そのような変化に対応するための猶予を確保するものでもある。

もちろん、どれだけの猶予が必要かは家庭によって異なる。経済的な困難を本人の工夫だけで解決できるとも限らない。

しかし、将来の不安を完全に取り除くことを目指せば、貯蓄には終わりがなくなってしまう。

将来の親の不在に備えるために働き続け、その結果として現在の親の不在を生み出しているとすれば、いささか奇妙な話である。

## 育児休業という生活実験

私はこれまで10年近く働いてきた。

その間、衣服を購入し、自動車を利用し、食事を楽しみ、様々な経験をしてきた。

何が自分にとって必要なのか。何にお金を使えば満足できるのか。そうしたことを実験してきた期間でもあったように思う。

私には大量の衣服は必要なかった。頻繁に外食する必要もなかった。新車である必要もなかった。

必要なものを見極めながら生活を営み、将来に備えてお金を蓄えてきた。

そして現在、私は育児休業を取得している。

朝には創作活動を行い、日中は子供と支援センターに出かける。家族と食事をし、編み物をしたり、美術館を訪れたりもする。

かなり充実した生活である。

これまでの蓄えや育児休業の制度、家族の協力があってこそ成立している生活ではあるが、私にとっては貴重な実験の機会となっている。

これまでは働くことによって得られるお金の価値を知っていた。

育児休業を取得したことで、働く時間を減らすことによって得られるものの価値も知った。

実際に二つの生活を経験したことで、自分が何を求めて働いているのかを改めて考えるようになったのである。

## これからどれだけ働くか

育児休業が終わった後、以前と同じ量の労働をする必要があるのだろうか。

時間を持て余すから働くという人もいるだろう。労働そのものに充実感を見いだす人もいる。

しかし、私には時間を持て余すという感覚がほとんどない。そして、現在の仕事は暇を埋めるために行うには、いささか大変な仕事である。

生活に必要な収入を得ながら、子供や家族と過ごす時間、創作活動に取り組む時間を確保する。

そのために、育児休業後は時短勤務という働き方を選択したいと考えている。

実際にどの程度の労働量で生活が成立するのかは、まだ分からない。育児休業が一つの生活実験であったとすれば、時短勤務は次の生活実験になるだろう。

今回のお金の講座を聞きながら、私は様々な疑問を紙に書き出していた。

子供にいくらお金をかけるべきなのか。老後にいくら必要なのか。貯蓄をするべき時期はいつなのか。子供と過ごす時間をいくらで買うのか。

しかし、結局のところ、私は育児休業後に働く時間を減らしたいのである。

その選択に自分自身が納得するために、これほど様々なことを考えているのかもしれない。

お金を稼ぐことによって生活を豊かにしようとしているのであれば、既に手に入れられる豊かな生活を、これ以上の収入のために手放す必要があるのだろうか。

今の私にとって、お金について考えることは、これからの時間の使い方について考えることでもある。

## 付録：お金に関する問いと、現時点での回答

講座を聞きながら手帳に書き出した疑問について、ChatGPTとの対話を通じて考えを整理した。

以下は普遍的な正解ではなく、現在の私なりの回答や、今後検討するための指針である。

### 子育て・教育資金

| 問い | 現時点での回答 |
| --- | --- |
| 子供を育てるのにいくらかかるのか | 平均額を目標とせず、生活費、教育費、経験費などに分解して考える。 |
| 子供にいくら投資するのか | 金額を先に決めるのではなく、子供に何を提供したいのかを考える。 |
| 子供にお金をかけるべき時期はいつか | その時期にしか得られない経験や、子供が必要としているものを優先する。 |
| 小学生の時期は貯蓄期なのか | 教育費が比較的少ない場合には貯蓄しやすいが、必ずしも貯蓄を優先する必要はない。 |
| 貯蓄せず、お金を使うべき時期はいつか | 後から取り戻せない時間や経験に価値を見いだしたときである。 |
| 習い事にいくら使うべきか | 本人の関心や活動の様子を見ながら判断する。 |
| 私立高校や大学、下宿などの費用はどうするか | 想定する進路ごとに必要額を試算し、本人とも相談する。 |
| 留学や芸術、研究への支援はどこまでするか | 本人の行動や目的を確認し、周囲の意見も聞きながら可能な範囲で支援する。 |
| 親がすべての教育資金を用意する必要があるのか | 必ずしもそうではない。奨学金なども含め、本人と実現方法を考える。ただし返済負担には注意する。 |

### 家計・貯蓄・老後資金

| 問い | 現時点での回答 |
| --- | --- |
| 月の生活費はいくら必要なのか | 平均値ではなく、自分たちの実際の支出を基準とする。 |
| 月の収支をいくらに定めるか | 望む生活と将来への備えから逆算する。 |
| 毎月の収支を黒字に保つべきか | 長期的に生活が成立するのであれば、育児休業などによる計画的な赤字も選択肢になる。 |
| 手取り収入の範囲内で生活すべきか | 長期的には必要な考え方だが、毎月単位で厳密に守る必要はない。 |
| 貯蓄額の目安はあるのか | 生活を維持し、環境の変化に対応するために必要な金額を考える。 |
| ひとり親になった場合の生活費はいくらか | 住居費、就労収入、遺族年金や公的支援などを踏まえ、個別に試算する必要がある。 |
| 生命保険はいくら必要なのか | 既存の資産や公的保障では補えない経済的な損失を基準に考える。 |
| 老後資金はいくら貯めるべきか | 年金収入と想定する生活費の差額を基準とし、住居費や医療・介護費も考慮する。 |
| 65歳時点で2,000万円必要なのか | 一律に必要とはいえない。生活水準や年金額、資産状況によって異なる。 |
| 中古住宅を購入した方がよいのか | 購入費用だけでなく、修繕費や税金、住み替えの自由度なども含めて判断する。 |
| いつ貯蓄をやめてよいのか | 将来への備えが一定程度確保され、追加の貯蓄よりも現在の時間や経験に価値を感じるときである。 |

### 労働・時間・資産形成

| 問い | 現時点での回答 |
| --- | --- |
| 子供と過ごす時間をいくらで買うか | 育児休業や時短勤務による減収を、得られる時間の対価として捉える。 |
| 時短勤務にはどのような価値があるのか | 収入の減少だけでなく、家族との時間や創作活動、心身の余裕なども評価する。 |
| 働く時間を減らしてもよいのか | 必要な生活費と将来への備えを確保できるのであれば、検討する価値がある。 |
| 副業でお金を増やすべきか | 得られる収入だけでなく、失われる時間や活動自体の価値を考える。 |
| 自営業という働き方はどうか | 収入の安定性、時間の自由度、事業に伴う負担などを比較する必要がある。 |
| FIREを目指すべきか | 完全な経済的自立だけを目標とせず、必要な労働量を減らすという選択肢もある。 |
| ブログやYouTubeで収益を得るべきか | 収益だけでなく、表現や記録、技能の獲得といった活動そのものの価値も考える。 |
| 自分の労働時間は1時間いくらなのか | 実質的な収入を拘束時間で割り、その金額で自分の時間を提供したいか考える。 |
| NISAを利用するべきか | 資産形成の目的と運用期間を明確にし、近いうちに必要となる資金とは分けて考える。 |
| こどもNISAと親のNISAのどちらがよいのか | 資産の所有者、使途の自由度、制度上の制約によって判断する。具体的な制度内容は別途確認が必要である。 |
| 時短勤務と社会保険の関係はどうなるのか | 勤務時間や賃金、適用条件によって異なるため、実際の勤務条件が決まった段階で確認する。 |
| 育児休業を取得した経験を今後どう生かすか | 時間のある生活を実際に経験した結果を踏まえ、今後の労働量を考える。 |

こうして問いを並べてみると、私がお金について知りたかったことの多くは、制度や金額そのものではなく、生活の中でどのような判断をすればよいのかということであったように思う。

そして、その判断の基準となるのは、自分がどのような生活を送りたいのかという問いである。
